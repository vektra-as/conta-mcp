# docs/

`conta-external-api.json` er Contas egen OpenAPI 3.0.3-beskrivelse av det offentlige
API-et (`https://api.gateway.conta.no`). Den er lagt ved som referanse for feltnavn og
schemas, og er ikke dekket av MIT-lisensen til dette repoet.

Den offisielle og oppdaterte dokumentasjonen publiseres av Conta:

- Kom i gang: <https://hjelp.conta.no/api>
- Swagger (produksjon): <http://docs.gateway.conta.no>
- Swagger (sandkasse): <http://docs.gateway.conta-sandbox.no>

Kopien her er hentet i juli 2026. Hent en ny kopi fra Swagger-siden og sammenlign før du
legger til nye verktøy, siden Conta kan ha endret API-et siden.
